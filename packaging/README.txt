GlassButterfly Screensaver
==========================

A minimal, beautiful screensaver: a liquid-glass clock and date over your
wallpaper, with realistic 3D butterflies drifting gently across the screen.


INSTALL
-------
1. Right-click "GlassButterfly.scr" and choose "Install".
   (If Windows shows a blue "protected your PC" warning, see the next section.)
   Windows opens its Screen Saver Settings panel with GlassButterfly selected.

2. Click "Preview" to see it full screen. Move the mouse or press any key to
   exit the preview.

3. Click "Settings" to customize:
      - Background: pick one of the three built-in wallpapers, or choose your
        own image from your PC.
      - Clock: toggle 24-hour time and whether seconds are shown.
      - Butterflies: choose how many appear (0 to 3).

4. Set the "Wait" time, then click OK. GlassButterfly starts automatically
   when your PC has been idle for that long.


IF WINDOWS SHOWS A "WINDOWS PROTECTED YOUR PC" WARNING
------------------------------------------------------
This appears because the file is new and not code-signed - it does not mean
anything is wrong. To continue: click "More info", then "Run anyway".


IMPORTANT
---------
Keep GlassButterfly.scr somewhere permanent (for example, your Documents
folder) BEFORE you click Install. Windows remembers the screensaver by its
file location, so if you move or delete the file afterwards, it will stop
working until you Install it again from its new location.


REQUIREMENTS
------------
- 64-bit Windows 10 or Windows 11.
- Microsoft Edge WebView2 Runtime. This is already installed on Windows 11 and
  on most up-to-date Windows 10 PCs, so you almost certainly need nothing extra.
  If the screensaver shows only a black screen, install the free "Evergreen"
  runtime from:
      https://developer.microsoft.com/microsoft-edge/webview2/


UNINSTALL
---------
Open Screen Saver Settings (right-click the desktop > Personalize > Lock
screen > Screen saver, or run:  control desk.cpl,,@screensaver ) and choose a
different screensaver, or "(None)". You can then delete GlassButterfly.scr.

Your saved settings live at:   %APPDATA%\GlassButterfly
Cached files live at:          %LOCALAPPDATA%\GlassButterfly
Both folders are safe to delete after uninstalling.
